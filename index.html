One-time setup. The apps list is stored in this repository's apps.json file, so the admin needs a GitHub Personal Access Token to edit it. Tap "Setup guide" below if this is your first time.
1. Go to github.com/settings/tokens?type=beta and tap "Generate new token"
2. Give it any name and choose a long expiration (or "No expiration")
3. Under "Repository access", select only this repository
4. Under "Permissions" → "Contents", choose "Read and write"
5. Generate the token, copy it and paste it here. It is saved only in this browser.
