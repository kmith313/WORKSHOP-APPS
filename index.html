🔒 Admin Unlock

Sirf ek baar setup karna hai. Apps ki list is GitHub repo ki apps.json file mein save hoti hai — admin ko ek GitHub Personal Access Token chahiye taaki wo edit kar sake. Neeche "Setup guide" dabayein agar pehli baar kar rahe hain.
1. github.com/settings/tokens?type=beta par jayein aur "Generate new token" dabayein
2. Naam kuch bhi rakhein, Expiration "No expiration" ya lambi rakhein
3. "Repository access" mein sirf apna repo chunein (jahan ye app-repository host hai)
4. "Permissions" → "Contents" → "Read and write" set karein
5. Token generate karke copy karein aur yahan paste karein — ye sirf isi browser mein save hoga, kahin aur nahi jayega
